# Enviroments 新用户上手指南

这份文档给第一次注册和使用 Enviroments 的用户看。你可以按下面顺序熟悉这个应用：先登录，再录入服务器和交换机，最后使用 Web SSH、文件管理和组网图。

## 1. 注册与登录

打开 Enviroments 页面后，先创建账号。

1. 点击注册入口。
2. 填写用户名和密码。
3. 注册成功后使用同一账号登录。

登录后，系统会把你的登录状态保存在当前浏览器中。后续访问服务器、交换机、文件、日志和 Web SSH 都会自动带上登录凭证。

## 2. 熟悉主界面

左侧是主要功能入口：

- 服务器：管理服务器、查看状态、打开详情、Web SSH、文件管理。
- 交换机：管理交换机、采集交换机信息、关联服务器。
- 我的收藏：只查看你收藏的服务器。
- 组网图：根据服务器网口 MAC 和交换机 MAC 表生成拓扑图。

右上角可以切换明暗主题。服务器和交换机数量、在线状态等统计信息会随当前页面变化。

## 3. 添加第一台服务器

进入服务器页面，点击添加服务器。

建议至少填写：

- IP 地址
- SSH 端口，默认是 22
- 系统类型
- SSH 用户名
- SSH 密码，或后续使用密钥方式
- 标签，例如 `测试`、`生产`、`GPU`
- 备注，例如机器用途、负责人、机柜位置
- BMC 信息，如果需要记录带外管理地址

保存后，系统会自动尝试检测在线状态并采集服务器详情。详情可能包括系统版本、CPU 型号、内存、网卡、PCI 信息等。

## 4. 使用服务器列表

服务器列表支持这些常用操作：

- 搜索 IP、标签、系统版本、CPU 型号和备注。
- 点击状态检测单台或全部服务器在线情况。
- 点击收藏星标，把常用服务器加入我的收藏。
- 点击标签、备注、DPU 单元格，可以直接编辑。
- 点击占用，把服务器标记为自己正在使用；使用完后点击释放。
- 点击列显示按钮，可以隐藏或显示 IP、系统版本、CPU 型号、标签、备注、DPU、BMC、使用人、关联交换机等列。
- 拖动表头分隔线，可以调整列宽。

如果列表字段太多，建议先隐藏 BMC 密码、BMC 用户名、DPU 等不常看的列，让列表更清爽。

## 5. 查看服务器详情

在服务器列表点击查看详情。

详情页通常会显示：

- 基本信息：IP、系统类型、在线状态、标签、备注。
- 采集信息：系统版本、CPU、内存、网卡和 PCI 信息。
- 详情记录：可以手动写排障记录、装机记录、业务用途等。
- 文件管理：通过 SFTP 浏览服务器目录、上传和下载文件。
- 日志：查看状态检测、详情采集、编辑变更等历史记录。

如果采集信息过旧，可以在详情页手动刷新。

## 6. 使用 Web SSH

在服务器列表点击 Web SSH，会打开一个新的终端页面。

Web SSH 适合：

- 快速登录服务器执行命令。
- 临时排查问题。
- 不想离开浏览器时进行简单运维。

打开后的浏览器标签标题会显示服务器 IP，方便多个终端页面之间区分。

如果 Web SSH 打不开，优先检查：

- 服务器是否在线。
- SSH 端口是否正确。
- 用户名和密码是否正确。
- 部署环境是否允许浏览器访问 WebSocket。

## 7. 添加交换机

进入交换机页面，点击添加交换机。

建议填写：

- 交换机名称
- 管理 IP
- SSH 端口
- 用户名和密码
- 标签和备注

保存后可以采集交换机详情。当前交换机采集主要用于获取设备版本等信息，并为后续组网图发现提供登录入口。

## 8. 关联服务器和交换机

组网图发现依赖“服务器与交换机的关联关系”。你可以从服务器列表或交换机列表维护关联。

推荐流程：

1. 先添加服务器。
2. 再添加交换机。
3. 给每台服务器关联可能连接到的交换机。
4. 进入组网图页面，点击重新生成拓扑图。

不要求一开始就完全准确。只要把服务器可能连接的交换机加入关联范围，系统会通过 MAC 表进一步判断实际端口。

## 9. 使用组网图

进入组网图页面后，可以看到交换机和服务器的连接关系。

常用操作：

- 点击重新生成拓扑图，立即执行一次链路发现。
- 滚轮缩放画布。
- 按住画布拖拽移动。
- 拖动底部横向条查看右侧更多交换机。
- 点击服务器或交换机，高亮相关链路并查看接口信息。

链路发现的大致过程：

1. 获取服务器上状态为 UP 的物理网口和 MAC 地址。
2. 触发服务器网口发包，让对端交换机学习 MAC。
3. 到关联交换机上读取 MAC 地址表。
4. 匹配服务器 MAC 对应的交换机接口。
5. 将结果保存为拓扑链路并渲染到页面。

如果一条关联线没有发现实际端口，通常表示交换机没有学到该 MAC、关联交换机不正确、服务器网口未连通，或交换机账号没有查询 MAC 表权限。

## 10. 日常使用建议

- 服务器刚录入后，先检测状态并刷新详情。
- 给服务器和交换机补充标签，后续搜索和筛选会轻松很多。
- 对多人共用的服务器，使用占用和释放功能减少冲突。
- 常用服务器加入收藏，日常从我的收藏进入。
- BMC 密码等敏感信息按团队规范填写和管理。
- 组网图生成前，先确认服务器和交换机已经建立关联。

## 11. 常见问题

### 登录后接口提示无权限

通常是登录状态过期。退出后重新登录即可。

### 服务器显示离线，但实际能 ping 通

应用检测的是 SSH 端口是否可达，不只是 ICMP ping。请确认 SSH 端口、网络访问策略和防火墙。

### 服务器详情采集失败

常见原因是 SSH 用户名/密码错误、端口错误、账号没有执行采集命令的权限，或目标系统缺少相关命令。

### Web SSH 打开后没有内容

先确认服务器 SSH 可以正常登录。如果是开发环境，还要确认前端代理支持 WebSocket；生产环境使用 Nginx 或其他网关时，也需要开启 WebSocket 转发。

### 组网图没有发现端口

可能原因：

- 服务器没有关联到正确交换机。
- 服务器网口不是 UP 状态。
- 交换机没有学习到服务器 MAC。
- 交换机账号没有执行 MAC 表查询命令的权限。
- 交换机命令输出格式暂未被解析。

可以先在交换机上手动执行 MAC 查询命令，确认是否能看到服务器网口 MAC。
